# Document Management System (DMS) Master List

## 1. Governance Policy
In accordance with **ISO 9001:2015 Clause 7.5**, this registry identifies the current valid version of all controlled technical documentation for the OmniGov project.

*   **Document Identification**: Every document is assigned a unique alphanumeric code.
*   **Version Control**: Version numbers are included in the filename and document header.
*   **Retention**: Previous versions are superseded by the latest release.
